# Post-Milestone Documentation Patterns

**Cycle**: 219 | **Date**: April 2026

---

## Key Finding: Top Hacks Use Layered Documentation

Unbound's documentation ecosystem reveals a three-layer pattern that Legends of Hoenn hasn't considered:

1. **Developer-authored docs** (Google Docs/spreadsheets): Shipped with releases. Cover encounter tables, trainer teams by difficulty level, evolution methods. Created by the dev team. This is what #115 asks for.
2. **Community-built wikis** (Miraheze, Fandom): Created by players AFTER the hack reaches critical mass. Unbound has 3 separate wiki sites. These are organic and can't be forced.
3. **Companion tools** (Nuzlocke trackers, Pokedex apps): Third-party tools that consume documentation data. pokemonunboundpokedex.com is a custom site with searchable encounter/trainer data.

## Unbound Documentation Specifics

- 61 encounter locations, 467 wild Pokemon, 310 trainers — all documented
- Trainer docs organized by difficulty level (Insane/Expert/Difficult/Vanilla) — relevant since LoH has Challenge Mode
- Key contributors credited by name (Spectre, SevenK, SkiDY, Skeli) — community investment
- Encounter tables include wild, static, gift, trade, and swarm Pokemon separately

## Actionable Insight

The developer-authored layer is what LoH can ship NOW. The most impactful format for a decompilation hack is a README feature list + encounter/evolution guide. Trainer teams by difficulty level is a differentiator since few hacks document Challenge Mode equivalents separately.
