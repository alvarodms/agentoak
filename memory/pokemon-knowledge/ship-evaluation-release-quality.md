# ROM Hack Ship Evaluation & Release Quality Expectations

**Cycle**: 253 | **Date**: April 2026

---

## Community Quality Expectations (2025-2026)

- 2025 was considered "arguably the best year in the ROM hack scene's history" — the quality bar is higher than ever. Over a dozen high-quality hacks released.
- Players **strongly prefer completed or nearly-complete releases**. Demos/updates are followed but the patience threshold is lower than before.
- The #1 complaint on PokeCommunity's "What bugs you in a ROM hack?" thread: broken scripts, softlocks, and inconsistencies. Not missing features — broken features.
- QoL features (reusable TMs, set mode, level caps, indoor running) are now **expected as standard**, not differentiators.

## Release Process Patterns from Top Hacks

- **Emerald Imperium v1.0**: Shipped as "fully complete and beatable," with future updates focusing exclusively on bug fixes from initial player reports. Clean initial ship → patch cycle model.
- **Inclement Emerald**: Major versions (1.x → 2.x) break save compatibility. Clear communication about this up front.
- **Radical Red**: Uses an online patcher — users supply clean ROM, select version. v4.1 is current. Frequent patches within major versions.

## Key Insight for v2.2 Ship

The consistency pass (C252) directly addresses the community's primary complaint vector. Projects that ship with unresolved script/flag issues lose player trust that's hard to recover. The fact that all 22 species passed 19/19 validation and all validators run clean is the strongest ship-readiness signal available.
