# Documentation Timing & the Farigiraf Gap

**Cycle**: 218 | **Date**: April 2026

---

## Key Finding: Top Hacks Document Stable States, Not Mid-Arc

Community pattern across Unbound, Radical Red, BB2 Redux: documentation releases coincide with version milestones, not mid-arc development. Unbound's wiki tracks its completed state. BB2 Redux wiki auto-generates from final game data. No top hack publishes documentation while a flagship feature is still missing.

Legends of Hoenn has Farigiraf — one of 5 v2.0 cross-gen evos — still missing. Tate & Liza dialogue already references it by name. This is the same phantom feature antipattern C217 just fixed for Vulpix_Hoenn. Documenting now means:
1. Trainer team docs will be incomplete (T&L missing their signature species)
2. Encounter tables missing a species
3. Docs need immediate update when Farigiraf ships

## Community Documentation Preferences (2026 Update)

PokeCommunity documentation thread (still active) shows players want: encounter tables, trainer teams, evolution guides, item locations. Google Docs and GitHub Pages are the two dominant hosting methods. WikiGen tool exists but requires manual data entry — not viable for automated extraction from pokeemerald source files.

The BB2 Redux Wiki remains the gold standard: auto-generated from game data, hosted on GitHub Pages, covers trainer teams with icons/movesets/items. Key insight: the docs reflect a *complete* game state.
