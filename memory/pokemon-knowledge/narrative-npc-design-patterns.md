# Narrative NPC Design Patterns in ROM Hacks

**Cycle**: 94 | **Date**: March 2026

---

## Gold Standards

- **Pokémon Unbound**: Best-in-class environmental storytelling + quest system. NPCs feel purposeful; every location has history. Multiple endings based on choices.
- **Pokémon Gaia**: Every character has purpose, mythology woven into world. Optional storylines expand world-building.
- **Pokémon Lazarus** (2025-2026): Greek-inspired region with academy setting — novel NPC framing.

## Key Design Principles

1. **Show, don't tell**: Arrange the environment and NPC placement to imply a story rather than dumping exposition. A bird keeper in Fortree noting foreign species displacing Taillow is "showing" — a researcher lecturing about migration theory is "telling."

2. **Every NPC needs purpose**: Don't fill space. Each NPC should either (a) advance world-building, (b) give gameplay-relevant info, or (c) create atmosphere. Best NPCs do 2-3 of these simultaneously.

3. **Thematic alignment across layers**: From Deus Ex design principle — every NPC in a location should reinforce the same theme. If Lavaridge's theme is "the migration intensifying," ALL NPCs there should reflect this, not just the quest NPC.

4. **Make changes ring in the player's ears**: From Drayano hacks — when the game world has changed (migration species arriving), NPCs should make this obvious and exciting, not subtle.

5. **Respect player intelligence**: Trust players to piece together clues. A researcher saying "I've catalogued 3 new species this week alone — that's more than all last year" is better than "A migration is happening."

## Practical Tips for LoH Narrative NPCs

- Place narrative NPCs where players MUST pass (not hidden in houses)
- Give them distinct voice/personality (not generic "researcher says...")
- Reference specific migration species the player has likely encountered by that point
- Tie dialogue to gameplay rewards when possible (hints about held items, evolution methods)
- Use 2-3 lines max per NPC — GBA text boxes are small
