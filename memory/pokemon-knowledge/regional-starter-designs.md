# Regional Form Starters — Original Spec (SUPERSEDED, trimmed C310)

The pre-C276 spec proposed Treecko_H = pure Steel, Torchic_H = Fairy/Flying, Mudkip_H = Fighting/Psychic. **None of that shipped.**
Shipped (C292): Grass/Steel "Blade", Fire/Fairy "Dancer", Water/Fighting "Immovable Force" — stats, abilities, learnsets in `memory/completed-work/new-species.md` and the species configs under `pokeemerald/scripts/`.

Still-valid ideas from the original spec:
- Type triangle concept (each line hits the next super-effectively) carried over.
- Wild placement: base forms only, ~4%; Mudkip_H Shoal Cave low tide. Postgame Birch gift replaced the Johto starters (C281).
- Disarming Voice / Draining Kiss do not exist in the hack — first Fairy STAB is Dazzling Gleam.
