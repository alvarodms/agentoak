# Gym Rematch Tier Design Patterns from Top Hacks

**Cycle**: 101 | **Date**: March 2026

---

## Core Design Philosophies

### Radical Red
- Forced Set mode, no bag in boss fights, soft level cap
- Gym teams **cover their own weaknesses** (anti-meta coverage)
- Postgame rematches scale to player's highest-level Pokémon
- Late bosses randomly pick from 3 possible teams (replayability)
- Max IVs, proper EV spreads, optimized movesets + held items

### Inclement Emerald / Elite Redux
- Preserves vanilla 4-tier rematch system but dramatically enhances teams
- Elite Redux: every rematch **individually crafted** (not formulaic level scaling)
- No day-wait for rematches (QoL improvement)
- Singles or Doubles choice for rematches
- Considers all new abilities/moves from engine changes in team design

### Emerald Azure (2025-2026)
- All trainers EV-trained; player expected to assign EVs too
- Gym themes tightened (e.g., Wattson = Electric/Steel "race-car" theme)
- Smart AI, no healing items in battle, forced Set mode

## Key Takeaways for LoH Pillar 2

1. **Each tier should feel like a different fight**, not just +5 levels. New species, new strategies, new items.
2. **Anti-meta coverage** is the hallmark of good gym design — gym leaders should have answers to their type weaknesses.
3. **Migration species as surprises**: Tyranitar on Roxanne Tier 4 is a 600 BST pseudo-legendary — it should feel like a genuine threat, not a filler slot.
4. **Item variety across tiers**: Tier 1 = Oran/Sitrus. Tier 2 = type-boost items. Tier 3 = Lum Berry/White Herb. Tier 4 = Choice Band/Leftovers.
5. Community strongly prefers **crafted variety** over formulaic scaling.
