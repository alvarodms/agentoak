# v1.0 Launch Best Practices — What Players Expect

**Cycle**: 143 | **Date**: April 2026

---

## What Successful ROM Hack Launches Include

### Release Page / README Essentials
- **Feature list**: Comprehensive, organized by category (story, mechanics, QoL, difficulty)
- **What's changed from vanilla**: Players want to know exactly how this differs from base Emerald
- **Spoiler-free postgame teaser**: Hint at content depth without revealing specifics
- **Boss documentation**: Some top hacks (Unbound, Radical Red) provide boss team details separately so players can strategize
- **Difficulty description**: Clear explanation of how hard the hack is and whether difficulty options exist

### Player Expectations for v1.0 (2025-2026 landscape)
- Fully completable main story + some postgame content (minimum bar)
- Revamped learnsets and trainer teams (not just vanilla with new encounters)
- Quality-of-life improvements expected as standard (reusable TMs, better HMs, etc.)
- Post-launch support channel (Discord/GitHub Issues) for bug reports
- Community engagement and transparency about what's included vs. planned

### Common Launch Pitfalls
- Releasing without end-to-end flag chain testing (progression blockers tank reviews)
- Feature list that oversells — players notice when "custom trainers" means only 3 were changed
- No documentation of difficulty level — players frustrated by unexpected spikes or lack thereof
- Missing credits/attribution for assets or tools used

### What Sets Top-Tier Hacks Apart (2025-2026)
- Pokémon Unbound: massive feature list, multiple difficulty modes, thorough documentation
- Radical Red: clear difficulty identity, competitive-viable movesets, honest about being hard
- Inclement Emerald: QoL focus, modern mechanics backported, well-documented changes
- Complete Crystal (2026): clean v1.0 release with itemized changelog and community Discord
