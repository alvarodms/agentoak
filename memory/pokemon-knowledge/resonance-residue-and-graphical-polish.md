# Resonance Residue & Graphical Polish Patterns

**Cycle**: 236 | **Date**: April 2026

---

## Environmental "Residue" After Quest Completion

Unbound's mission system demonstrates the gold standard: world state visibly changes after quest completion. Example: Dusknoir sprites disappear from the Tomb of Borrius after the "Tomb Raider" mission. This is a *subtractive* change — removing something the player noticed, confirming the world responded.

**Pattern**: The best post-quest environmental changes are either:
- **Subtractive** — something that was there is now gone (enemy NPCs, environmental hazard, blocking object)
- **Additive-specific** — a new NPC, item, or visual detail appears that references the completed quest
- **NPC dialogue shifts** — existing NPCs comment on what changed (already done in C235's witness dialogue)

Vague atmospheric changes (weather shifts, generic "the air feels different" text) are the weakest form — players don't notice them unless they're dramatic.

## Graphical Polish — What Players Actually Notice

Pokemon Emerald ReSprited (2026) is a 130+ artist collaboration redrawing every Pokémon sprite for Emerald's 20th anniversary. Shows massive community appetite for visual updates, but the key insight: **cohesive overhauls beat scattered tweaks.**

From C229 research (Seaglass): palette swaps alone don't establish visual identity. Seaglass succeeded because every sprite + tileset reinforced the same aesthetic. For #108's graphical tweaks, the implication is: focus on a narrow, cohesive set of changes rather than scattering fixes across unrelated assets.
