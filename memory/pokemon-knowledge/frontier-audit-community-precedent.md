# Frontier Audit: Community Precedent & Completion Strategy

**Cycle**: 81 | **Date**: March 2026

---

## Key Finding: HGSS Competitive Battle Factory Hack

A dedicated PokéCommunity project replaced **all 950+ Battle Factory sets** with Smogon-competitive ones. The creator audited every single set manually. Community response was overwhelmingly positive — players specifically praised that Factory opponents finally "make sense" post-split.

## Emerald Battle Revolution Approach

Uses a **stat-affinity filter** for movesets: no special moves on physical attackers, no physical moves on special attackers. This automated approach catches the obvious mismatches quickly. LoH's manual audit (Cycle 80 punches) is more thorough but slower.

## Remaining LoH Frontier Work

~117 entries use Crunch (now Physical, was Special) or Shadow Ball (now Physical, was Special). Key affected mons:
- **Crunch on special attackers**: Gengar, Alakazam, Kadabra, Espeon, etc. — these need Crunch swapped for Dark Pulse or Shadow Ball alternatives
- **Shadow Ball on special attackers**: Already Physical post-split. Mons like Gardevoir, Misdreavus using Shadow Ball for coverage now waste their SpAtk stat
- **Hyper Beam**: Now Physical. Special attackers using it need Hyper Beam → special alternative

## Recommendation

Complete the Crunch/Shadow Ball batch in Cycle 81. This finishes the P/S split audit — a differentiator that puts LoH in elite company alongside Energized Emerald and Modern Emerald. After that, the Frontier is fully polished and the project can pivot to narrative content (Birch quest).
