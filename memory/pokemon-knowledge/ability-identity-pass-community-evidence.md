# Ability Identity Pass — Community Evidence (C262)

**Cycle**: 262 | **Date**: April 2026

---

## Key Finding: Swift Swim + Water/Rock = Kabutops Clone Problem

Gligar/Gliscor_Hoenn (Water/Rock) with Swift Swim would directly overlap with Kabutops, which already exists in the Gen 3 Hoenn dex as Water/Rock + Swift Swim. Community consistently criticizes regional forms that feel like mechanical clones of existing Pokémon — the form should create a *new* strategic identity, not duplicate one.

## PokeCommunity: Ability Changes Must Justify Themselves

From [the "changing existing Pokemon" thread](https://www.pokecommunity.com/threads/your-perspectives-on-changing-already-existing-pokemon.541820/): "type changes and ability changes are core elements that help identify a Pokémon. Any changes should be for the benefit of the game, not arbitrary." Players want each ability swap to have a clear gameplay payoff, not just thematic matching.

The Lumineon example was cited: Swift Swim on a Pokémon that doesn't benefit from it strategically feels like a wasted slot. Ability should reinforce what the Pokémon actually *does*.

## Radical Red: Ability IS the Form's Fantasy

Radical Red v4.1 Seviian forms succeed when the ability is inseparable from the form concept:
- Seviian Milotic (Ground): Sand Stream/Shore Up — the ability tells you it's a desert creature
- Seviian Wishiwashi: Schooling → Dragon transformation — the ability IS the gimmick

Pattern: **best regional form abilities create a niche that didn't exist before**. Worst ones just type-match.

## Radical Red: Seviian Form Integration Philosophy

Radical Red deliberately restricts Seviian forms: "Trainers in the main game will not have access to them, and you can only receive one before the post game." This prevents jarring players who dislike custom Pokémon. LoH takes the opposite approach (forms woven into world + trainers), which is bolder but means every form's ability needs to feel earned, not arbitrary.
