# Ability Audit — Holistic Roster Patterns

**Cycle**: 263 | **Date**: April 2026

---

## Ephemerald's "Stat-Ability Alignment" Lesson

Pokémon Ephemerald (382 Sapphosian forms) redesigned every Pokémon's type, movepool, AND abilities — but critically, also **flipped Atk/SpA stats to match the new typing and movepool**. The Pokémaniacal review praised forms where the stat spread, ability, and movepool formed a coherent package, and criticized forms where the ability didn't match what the stats wanted to do.

**Takeaway for LoH**: When auditing abilities, verify that each species' stat spread supports the ability. An ability like Swift Swim is wasted on a slow bulky tank that doesn't benefit from Speed doubling. Lightning Rod on a physical attacker that can't use the SpA boost (Gen 4+ only — Gen 3 Lightning Rod just redirects, no boost).

## Roster-Level Niche Mapping

Both Ephemerald (382 forms) and Radical Red (Seviian forms) design abilities at the **roster level**, not species-by-species. Ephemerald ensured all dual-type combos were unique; Radical Red ensured no two Seviian forms filled the same competitive niche. With 28 forms, LoH should map what strategic roles each ability creates across the full roster — looking for:
- Duplicate niches (C262 already flagged Swift Swim Gliscor_Hoenn = Kabutops clone)
- Missing roles (no Intimidate user? no weather setter? no hazard support?)
- Ability clusters (too many contact-punishment abilities like Poison Point, Effect Spore, Flame Body)

## Community Feedback Pattern

PokeCommunity threads show that players forgive uninspired typings but criticize abilities that feel "random." The ability is the last thing they evaluate and the first thing that feels wrong if it doesn't fit. "Type changes and ability changes are core elements that help identify a Pokémon. Any changes should be for the benefit of the game, not arbitrary."
