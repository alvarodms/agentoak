# Roamer Polish & QoL — Community Expectations

**Cycle**: 113 | **Date**: March 2026

---

## Key Findings

### What players hate about roaming legendaries
1. **Tedium of finding them** — random route movement with no tracking is universally disliked
2. **Losing progress on KO** — accidentally KOing a roamer and losing it forever is a top frustration
3. **No feedback on location** — players want some hint system (NPC, Pokédex, map indicator)

### How top ROM hacks address this
- **Re:Emerald**: Roamers respawn next day if KO'd; releasing a caught legendary respawns it too. Reworked roaming to be "less of a pain to find."
- **Radical Red**: Mix of roaming + fixed legendaries in postgame
- **Emerald Legacy**: Preserves nostalgia while adding QoL — considered gold standard for Emerald improvement hacks
- **Unbound**: Full postgame legendary quest chains with narrative context

### QoL expectations for modern Emerald hacks
- Faster text speed
- Reusable TMs (already common expectation)
- Updated HM mechanics
- Run by default
- No fishing minigame

### Tension: QoL vs. authenticity
Crystal Legacy review controversy shows some players push back on QoL that contradicts a hack's stated design philosophy. Important to be intentional about which QoL changes fit the hack's identity.

### Relevance to Legends of Hoenn
The beast system already has KO/caught distinction and 3-turn flee delay — both are player-friendly. The NPC sighting dialogues on Route 118 and Fortree provide location hints. The sequential release (one at a time) reduces confusion. These design choices already align with community expectations. Main gap: no respawn-on-KO mechanic (beasts are lost if KO'd).
