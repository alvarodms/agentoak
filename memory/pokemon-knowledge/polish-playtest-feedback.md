## 2025 Community Expectations for ROM Hack Polish

**UI Standards**: Modern ROM hacks include visual indicators for moves - "battle moves will show its type GFX and special/physical category when selecting them." Examples: Pokemon Recharged Emerald (v2.2.6) with "updated battle interface to a more modernized ui, following the base design of Pokémon BW adapted to GBA."

**Immersion Priorities**: Players prioritize "comprehensive content" and "visual enhancement" that "align the visual style with that of later Pokémon installments" for "a more visually engaging and immersive experience."

**Polish vs Features**: 2025 community strongly values "completion and stability" over "feature-rich but incomplete hacks." Top hacks like Pokemon Unbound succeed because "every feature feels polished and complete."

## Critical Playtest Feedback Patterns

**Vanilla Elements Break Immersion**: When a hack has strong thematic identity (like migration), remaining vanilla elements create jarring disconnects:
- Intro/cutscenes still showing vanilla content
- Starter routes not reflecting the hack's core concept
- Missing expected modern UI elements

**Physical/Special Split Implementation**: Community now expects visual indicators. Player quote: "are there any plans to implement the physical/special icons next to moves in the menus? I have a smooth brain and can't remember which is which."

**Options/Toggles**: Modern expectations include player choice for major mechanics (physical/special split toggle, difficulty options).
