# ROM Hack Starter Design Patterns

**Cycle**: 254 | **Date**: April 2026

---

## The Pseudo-Legendary Starter Pattern

**Unbound** popularized pseudo-legendary starters: Gible, Beldum, Larvitar. Community consensus is Gible (→Garchomp) is best. This has become a recognizable trope — other hacks using the same species feel derivative. LoH's Dratini/Bagon/Larvitar picks overlap heavily with Unbound's identity.

## Regional Form Starter Pattern

**Blazing Emerald** converts original starters into new types: Bulbasaur → Burnasaur (Fire), Charizard → Sealizard (Water). This is the stronger differentiator — it signals "this is a different game" from the title screen. A sequel (VariaBlue) is in development, suggesting the approach resonated.

**Key community insight**: Players react positively to regional form starters because they create immediate "this is different" recognition. The type-swapped Hoenn starters idea (Fire Treecko, Grass Mudkip, Water Torchic) from issue #154 aligns with this proven pattern.

## Implications for LoH

The Unbound comparison in #154 is valid. If LoH's v2.3 "Roots" vision is about making Hoenn feel transformed from the first route, regional form starters would be the strongest possible execution of that pillar — the player encounters the hack's identity before choosing their first Pokémon. However, creating 3 regional starter lines (9 species total with evolutions) is a massive scope commitment.
