# Lints (check_all) and generators

Moved verbatim from memory/codebase-facts.md in C380 (index: [../codebase-facts.md](../codebase-facts.md)). Current state, not a log: replace what a new fact makes redundant.

- **`make check_encounter_odds`** (C348, scripts/check_encounter_odds.cjs): Red Ink page species keep a minimum % of their home map's land slots (FLOORS table); `check(json)` is pure, so `--selftest` mutates in-memory copies. A wild-table edit that drops a page species below its floor is a design change, not tuning. check_playtest R5 only resolves `Label::` (double-colon) lines: any label named in a BEATS row must be declared `::` (C348).

- **`make check_object_tiles`** (C338, scripts/check_object_tiles.cjs): every literal setobjectxyperm/setobjectxy/EventMacro_DexBelieverPlace/EventMacro_InkBelieverPlace (C345) destination (and local_id start tiles on those maps) must be collision 0, elevation-compatible, not warp/door/water/ledge, and not on an always-present object's start tile; vanilla exceptions in ALLOWLIST, known Agent Oak NPC-in-wall cases in KNOWN_ISSUES (warning; empty since C339, verified C357). Its exports (C357: + readMapJson, readBin, isBadBehavior, collectDestinations, MAPS_DIR) are the reusable map.bin lookup; scripts/map_scan.cjs is the CLI built on them. (map.json start tiles only on maps with a scripted destination; check_beat_visibility V3 covers v3.1 beat objects, C354)

- **scripts/beats.json + scripts/lib/beats.cjs + check_beats.cjs (C367, loader C373)**: one row per shipped beat (23 rows; MIN_ROWS 23 lives in lib/beats.cjs, C394). Every reader goes through lib/beats.cjs (`BEATS_JSON=<file>` swaps in a scratch copy); check_playtest R5 and check_beat_visibility V/W derive their tables from rows (`mustReadEntries`/`visibilityEntries`/`traceEntries`, which reproduce the old hand tables key-for-key, so JSON.stringify parity is a valid check). Adding a postgame hide-flag beat = a `visibility` sub-object; an R5 flag read = `mustRead` (+ `mustReadScripts` when the key is an object_event script); a ring-style trace = `metatiles` + `traceName` (labels[0] is the ON_LOAD label, `from` is a hex string). check_beats B5 resolves `scenario.checkpoint` by parsing src/emulator/checkpoints.ts text (the boot map is the first `map: "MAP_*"` inside `const <NAME>: Checkpoint = {`), so keep that shape when editing checkpoints. check_object_tiles has no beat table: it parses EventMacro_*BelieverPlace/setobjectxy(perm) lines directly. `walkLabels(text, labels)` is a pure label walker for one scripts.inc: follows goto/call/goto_if_*/call_if_*/case/fall-through to labels in the same file, collects text args via ARG_POSITION (msgbox/message arg 1; trainerbattle_single 2,3 (+script 4); _no_intro 2; _double 2,3,4; _rematch 2,3), and flags any unlisted trainerbattle_* or any other command passing a *_Text_* label. readString() maps \n \l \p to spaces so /\bpen\b/ sees word edges. Text in data/text/*.inc (trainer defeat texts like IVAN's) is not read.

- **`make check_playtest`** (C341, scripts/check_playtest.cjs): guards data/scripts/playtest_den_tour.inc. The preset runs via RunScriptImmediately at the end of NewGameInitData (src/new_game.c), AFTER `EventScript_ResetAllMapFlags` (new_game.inc, 159 setflags, mostly FLAG_HIDE_* story NPCs that start hidden). So a preset only needs to set a FLAG_HIDE_* that vanilla flow sets mid-story; the ~20 den-route hides set by ResetAllMapFlags are already hidden in a fresh preset save, and the lint derives that set from source. To add a beat that the preset must keep live, add a row to its BEATS table; for a new FLAG_HIDE_* hit, prefer `setflag` in the preset if a badge-8 player would have finished the scene, otherwise add a HIDE_ALLOWLIST entry with a reason.

- **`scripts/map_scan.cjs`** (C357, `make check_map_scan`, in check_all): **use this before any tile placement instead of ad hoc map.bin reads.** `node scripts/map_scan.cjs <MAP> <x0-x1> <y0-y1> [--behavior MB_X] [--metatile 0xNNN] [--walkable]` or `<MAP> --at x,y`; MAP = MAP_ROUTE113 / ROUTE113 / Route113 (resolved through each map.json `id`). One line per tile: `x,y  0x20A Fallarbor_AshGrass  MB_ASHGRASS  c0 e3` (label from metatile_labels.h, prefix = tileset name minus gTileset_, primary if id < 0x200; `?` if none) + markers `[obj LOCALID|#n]`, `[warp -> MAP]`, `[coord]`, `[bg]`, `[runtime LOCALID (DexBelieverPlace|InkBelieverPlace|setobjectxyperm|setobjectxy)]` (check_object_tiles collectDestinations), `[setmetatile METATILE_X]`; ends `N tiles matched`. `--walkable` = collision 0, no warp/coord event, not isBadBehavior. Every run first checks the MAPGRID masks in include/global.fieldmap.h are 0x03FF/0x0C00/0xF000 (pure `checkMasks(text)`), else exits 1 "map.bin layout changed; update tileAt". Unknown map / out-of-bounds / bad args exit 1. Selftest (16 cases): R113 38,4 0x20A MB_ASHGRASS c0 e3; 38,8 0x218 MB_NORMAL; R106 54,15 0x124 MB_SAND; R113 x35-41 y3-8 MB_ASHGRASS = **24** tiles, none on y3 (memory said 26 until C357; the C353 row list sums to 24); 38,5 obj ELLIS, 38,6 runtime picnicker, 38,7 setmetatile NormalGrass, 33,5 warp; must-fail: --walkable drops 33,5 and the first wall tile, checkMasks rejects 0x07FF, ROUTE999, out of bounds. - **generate_species.cjs** `<config.json> [--dry-run] [--fill-missing]` (configs in `species_configs/`): 27 files. - **generate_trainer.cjs** `<config.json> [--dry-run]` (--dry-run prints the whole would-be file content, not a diff) (the config path is the FIRST argument; mode comes from the JSON's "mode", so `generate_trainer.cjs modify x.json` tries to open a file named "modify") (configs in `trainer_configs/`): `create` (new ID in opponents.h; never use it, it raises TRAINERS_COUNT), `reclaim` (since C385; codebase-facts.md "Reclaim a trainer slot") or `modify` (finds `partyName[]` by name, replaces the WHOLE array, so party size can change; rewrites the trainer's `.party = MACRO(name)` line). Running modify on an unchanged macro leaves trainers.h byte-identical. `scripts/verify_species.sh` takes the bare name (`HONCHKROW`), NOT `SPECIES_HONCHKROW` (that reports 13/27 false missing).
