# Codebase Facts

## Species Registration System

27 files per species — all handled by `generate_species.cjs`. Check: `scripts/check_species_registration.sh`. 3 naming conventions: `SPECIES_X`, `NATIONAL_DEX_X`, PascalCase `gMon*_X`.

**Per-species file count**: 27 generator files + 6 manual entries (`pokemon.c`: Hoenn dex, National dex, Hoenn→National order, front anim ID; `pokemon_icon.c`: 2). ~33 total.

**Cry system**: Custom species MUST add cry_ids.h entry `[SPECIES_X - 277] = <base_cry_id>`. Without it, defaults to cry ID 0 (Growlithe).

## Trainer System

**Three-file system**: `opponents.h` (IDs), `trainers.h` (metadata + macro), `trainer_parties.h` (party struct). All three must match. Macro/struct mismatch = crash. Validation: `scripts/check_trainers.sh`.

**Capacity**: TRAINERS_COUNT = 891; unreferenced IDs 462,485,486,633,634,853 (581 → TRAINER_PYRE_MOURNER C334; 117 → TRAINER_ROUTE119_STORM_CHASER C349; 173 → TRAINER_ROUTE113_ASH_CAMPER C350). Hand-verify each (computed-ID refs are invisible to the scan) before use; never bump TRAINERS_COUNT. 568 = TRAINER_JUAN_DUET (C322); 851/852 = TRAINER_MAXIE_RECKONING/TRAINER_ARCHIE_RECKONING (C326, constants renamed from TRAINER_RED/LEAF, arrays sParty_MaxieReckoning/ArchieReckoning). Link path is safe for reclaimed slots: `gTrainers` is `const` (ROM), and TRAINER_LINK_OPPONENT = 2048 is handled outside the table. Never bump TRAINERS_COUNT: SYSTEM_FLAGS follows TRAINER_FLAGS_END, so a bump breaks old saves. Rematch table: 5 tiers, all filled. **Repurposed slots**: TRAINER_WALLACE(+REMATCH_1-4) = Steven (C308); TRAINER_JUAN_1-5 = Wallace (C309) — constant names kept for those. 568 TRAINER_GRUNT_UNUSED → TRAINER_JUAN_DUET (C322) and 851/852 → *_RECKONING (C326) were renamed. Rename workflow: rename constant + `[ID]` block + party array first, then run generate_trainer.cjs in modify mode (it fixes the macro/struct).

**Double-battle trainers get fixed personalities** (`battle_main.c` CreateNPCTrainerParty): `doubleBattle == TRUE` → base personality 0x80 plus the trainer-name hash << 8, so the low byte is always 0x80. Ability is always slot 0, and gender is fixed per species (0x80 against the gender threshold: Luvdisc female, 50/50 species male). Don't build a doubles boss around a slot-1 ability (Lightning Rod Marowak, Water Absorb Mantine). When a doubles trainer's mon faints, `GetMostSuitableMonToSwitchInto` (battle_ai_switch_items.c) picks the replacement by type matchup, not party order, so planned "pairs" mix after the first KO.

**Tag/multi battles load at most 3 mons per opponent** (`battle_main.c` CreateNPCTrainerParty: `BATTLE_TYPE_TWO_OPPONENTS` → monsCount = PARTY_SIZE/2). Mossdeep Space Center (SPECIAL_BATTLE_STEVEN) is one, so any boss fought in a tag battle needs a ≤3-mon array or slots 4+ (often the ace) silently never appear. C316 fixed sParty_MaxieMossdeep (was 4 mons, Camerupt ace cut).

**Villain parties (C316)**: all 10 Maxie/Tabitha/Archie/Shelly/Matt arrays are generated from `scripts/trainer_configs/villain_*.json`. Ownership/collision check: `node scripts/audit_boss_species.cjs [--strict]` (BOSS_GROUPS regex map → per-boss species, ACCEPTED_OVERLAPS with allowed pairs, `COLLISIONS: N`; exit 1 only under --strict). Grunts/route trainers are not audited.

**Rival parties**: 30 arrays (5 encounters × 3 starter variants × 2 genders, mirrored). Postgame (C280): Lv70-73, 6 mons, IV 200, ace = Changed Three form.

## Dialogue Editing System (Cycles 24-26)

**Text format**: `\n` (line 2), `\l` (line 3+), `\p` (new page), `$` (terminator). Max ~35 chars/line. Smart quotes valid (charmap B1/B2). ASCII `"` (0x22) NOT in charmap. Em-dashes NOT in charmap — use `--`. Ellipsis = B0 in charmap. **Only valid escapes**: `\n`, `\l`, `\p`, `$`. Any other `\X` (e.g. `\e`, `\t`) causes build error.

**Safety**: `MSGBOX_NPC` labels safe to rewrite. `MSGBOX_DEFAULT` may have story logic.

**Script temp vars**: Only VAR_0x8000 through VAR_0x800B exist. VAR_TEMP_* reset on map transition — coord_events using them as guards fire once per visit.

## Wild Encounter JSON Rules

**File**: `src/data/wild_encounters.json`. Land: 12 slots (20/20/10/10/10/10/5/5/4/4/1/1%). Water: 5. Fishing: 10.

## Flag System Layout

Temp 0x00-0x1F (cleared every map load) → story/item flags → Hidden items 0x1F4-0x263 → Trainer 0x500-0x87A → System 0x87B+ → Daily 0x940-0x97F (cleared daily); FLAGS_COUNT 0x980. **Evaluated C334 by check_flag_values.cjs**: MAX_TRAINERS_COUNT is 891, so SYSTEM_FLAGS = TRAINER_FLAGS_END + 1 = 0x87B; the "0x860"/"0x85F" comments in flags.h (and a FLAG_UNUSED_0x863 name that is really 0x87E) are stale vanilla text. Never trust a hex in a flags.h comment or a FLAG_UNUSED_0xNNN name above 0x4FF; run `make check_flag_values` or evaluate the define. Custom flags 0x264-0x2BB (full since C336: 0x2BB = FLAG_DEN_METEOR_STEVEN_CHALK); further flags come from the verified FLAG_UNUSED pool listed in strategy-notes Flag space (rename the FLAG_UNUSED_0x* define in place). Den caught flags: 0x2B5 Mt. Pyre Torchic, 0x2B6 Meteor Falls Treecko, 0x2B7 Shoal Cave Mudkip. Beast: 0x881-0x886. Difficulty: 0x286. Reckoning: 0x2AB-0x2B4.

**Shoal Cave tide architecture**: `ShoalCave_LowTideEntranceRoom` handles BOTH tides — `OnTransition` calls `UpdateShoalTideFlag` then swaps layout. Object events on `LowTideEntranceRoom` appear in both tides. Use `call` subroutine pattern for OnTransition logic. **FLAG_SYS_SHOAL_TIDE SET = HIGH tide.** Only the Entrance and Inner rooms swap layouts (`setmaplayoutindex`), so their objects/bg_events exist at both tides (a sign there needs tide-aware text and a stand tile walkable in both layouts). The Lower, Stairs and Ice rooms are **low-tide-only maps**: at high tide the Inner Room warps to the Lower Room (4 at (15,19), 5 at (30,25)) sit on MB_OCEAN_WATER, and water is not in `IsWarpMetatileBehavior` (field_control_avatar.c:751), so they never fire; warp 3 (ladder at (19,14), elevation 4) is unreachable by walking or surfing. Surf can only start from elevation 3 and `CanStopSurfing` only lands on elevation 3 (field_player_avatar.c:729). Ledges (MB_JUMP_*) have collision 1 but `ShouldJumpLedge` runs before the collision check. Throwaway map.bin BFS recipe: u16 per tile, metatile bits 0-9, collision 10-11, elevation 12-15; behavior = low byte of `data/tilesets/{primary/general,secondary/cave}/metatile_attributes.bin` (secondary index = metatile-512).

## Repel System Architecture (C295, shipped C297)

**Script**: `data/scripts/repel.inc` — BW-style continuation prompt. Shows "REPEL's effect wore off", calls `Special_FindBestRepelInBag` to find best available (Max > Super > Repel), prompts "Would you like to use another {item}?", calls `Special_UseRepelFromBag` on yes.
**C helpers**: `src/field_specials.c` — `Special_FindBestRepelInBag()` sets `gSpecialVar_Result` to best item ID (or 0). `Special_UseRepelFromBag()` reads `gSpecialVar_0x8004`, calls `RemoveBagItem` + `VarSet(VAR_REPEL_STEP_COUNT, GetItemHoldEffectParam(...))`.
**Infrastructure**: `wild_encounter.c:883` calls `ScriptContext_SetupScript(EventScript_RepelWoreOff)`. `item_use.c:843` sets the var for manual use.

## Battle Animation System (C295, shipped C297)

**Main file**: `data/battle_anim_scripts.s` — `gBattleAnims_Moves` pointer table at top. 381 entries (0-380). `Move_COUNT` = generic fallback (basic hit + shake).
**Custom move animations (C297)**: Move_IRON_LEAF (Steel Wing metallic_shine + Leaf Blade slash), Move_SPORE_FIST (Ice Punch crystals + fist strike + IceCrystalEffectShort), Move_TIDAL_FLARE (Water Pulse bubbles + Ember fire particles). All use recomposed existing sprite templates — no new assets.
